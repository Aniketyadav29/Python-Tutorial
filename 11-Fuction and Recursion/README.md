# ⚙️ Module 11: Functions and Recursion

### 📌 Definition
A **Function** is a block of reusable code that only runs when it is called. Functions help in reducing code duplication and making the program modular.

---

### 📂 Function Types

1. **Without Parameters & Without Return**: Performs a fixed task (e.g., a simple greeting).
2. **With Parameters & Without Return**: Takes input data but doesn't send a result back.
3. **Without Parameters & With Return**: Sends data back to the caller without requiring input.
4. **With Parameters & With Return**: Takes input, processes it, and returns the result.

---

### 🛠️ Key Concepts

* **Parameters**: Variables listed in the function definition (the placeholders).
* **Arguments**: The actual values passed to the function when it is called.
* **Default Arguments**: Values that are used automatically if the caller does not provide an argument.
* **Recursion**: A process where a function calls itself to solve smaller sub-problems. It **must** have a **Base Case** to prevent infinite loops.

---

### 📊 Recursion Logic
The main idea of recursion is to break a complex problem into smaller, identical sub-problems.
* **Base Case**: The condition where the recursion stops.
* **Recursive Case**: The part where the function calls itself with a modified value.
