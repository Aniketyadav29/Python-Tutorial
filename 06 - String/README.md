# 🧵 Module 06: Strings and Manipulation

### 📌 Definition
A **String** is a sequence of characters enclosed in quotes. Python supports single, double, and triple quotes for defining strings.

---

### 📂 String Concepts

#### 1. Escape Sequence Characters
Special characters used to insert formatting that is otherwise difficult to type.
* `\n`: New Line
* `\t`: Tab space

#### 2. Basic Operations
* **Concatenation**: Joining two strings using the `+` operator.
* **Length**: Finding the total number of characters using `len()`.

#### 3. Indexing & Slicing
* **Indexing**: Accessing a single character at a specific position (starts at `0`).
* **Slicing**: Accessing a range of characters using `[start:stop]`.
* **Negative Indexing**: Accessing characters from the end of the string (starts at `-1`).

---

### 🛠️ Built-in String Functions

| Function | Description |
| :--- | :--- |
| `.endswith()` | Checks if the string ends with a specific value. |
| `.capitalize()`| Converts the first character to uppercase. |
| `.find()` | Returns the index of the first occurrence of a value. |
| `.replace()` | Replaces a specified value with a new one. |
| `.count()` | Counts the number of times a value appears. |
