# 📝 Python Course: Module 01 - Comments

### 📌 Definition
In Python, **comments** are notes you write in your code to explain what it does. They are completely ignored by the Python interpreter and do not affect the program's execution.

---

### 📂 Types of Comments

#### 1. Single-Line Comment
Used for short explanations or notes on one line.
* **Syntax:** Starts with the `#` symbol.
* **Example:**
  ```python
  # this is a single line comment
---
#### Multiline Comments:-
 These are used when a developer needs to write detailed explanations, documentation, or notes that span across multiple lines. While Python does not have a specific "multi-line" syntax like other languages, it uses triple quotes to achieve this.

#### 📂 Types of Multi-line Comments

In Python, you can create multi-line comments using two types of triple quotes:

#### 1. Triple Single Quotes (`'''`)
This method is commonly used for block comments or temporary disabling of code.
* **Syntax:** Enclose the text between three single quotes.
* **Example:**
  ```python
 '''
  this is a multi line comment
  line 1  
  line 2
  line 3
  line 4
  '''
#### 2. Triple Double Quotes(""")
Triple double quotes (`"""`) are used in Python to create multi-line comments. This method is the standard way to create **Docstrings**, which are used to explain the purpose of a module, function, class, or method.

---

### 📂 Usage & Syntax

* **Purpose**: This method is used for multi-line comments and is the standard for creating Docstrings in Python.
* **Syntax**: Enclose the text between three double quotes (`"""`).

#### 📝 Example:
``"""
this is also a multi line comment
line 1
line 2
line 3
line 4
"""
