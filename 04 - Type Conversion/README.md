# 🔢 Module 04 & 05: Type Conversion & User Input

### 📌 Definition
**Type Conversion** is the process of changing the data type of a variable from one type to another to perform specific operations.

---

#### 1. Implicit Type Conversion (Automatic)
* **Definition**: Python automatically converts one data type to another when it is needed—without loss of information.
* **How it works**: If you add an `int` and a `float`, Python promotes the `int` to a `float` to avoid losing the decimal precision.
* **Real-Life Analogy**: Like a bank automatically converting your physical cash into a digital balance when you deposit it.

#### 2. Explicit Type Conversion (Manual / Typecasting)
* **Definition**: When the programmer manually converts the type of data using built-in functions.
* **Built-in Functions**:
    * `int()`: Converts to an Integer.
    * `float()`: Converts to a Floating-point number.
    * `str()`: Converts to a String.
* **Real-Life Analogy**: Like manually translating a book from Hindi to English so a different audience can read it.

---

### 📊 Quick Comparison Table

| Conversion Type | Action | Controlled By | Example Function |
| :--- | :--- | :--- | :--- |
| **Implicit** | Automatic | Python Interpreter | `5 + 2.0 = 7.0` |
| **Explicit** | Manual | Programmer | `int("5")` |
