# 🔄 Module 10: Loops (Iteration)

### 📌 Definition
Loops are used to execute a block of code repeatedly until a specific condition is met. They are essential for automating repetitive tasks.

---

### 📂 Loop Types

#### 1. While Loop
Repeats a block of code as long as a condition remains **True**. 
* **Key Components**: Iterator Initialization, Stopping Condition, and Iterator Update.

#### 2. For Loop
Used to iterate over a sequence (list, tuple, string) or a range of numbers. It is more concise when the number of iterations is known.

#### 3. Range Function
Generates a sequence of numbers. 
* **Syntax**: `range(start, stop, step)`
* *Starts from 0 by default and stops before the specified stop value.*

---

### 🛠️ Control Statements

| Statement | Description |
| :--- | :--- |
| **break** | Terminate the loop entirely when a condition is met. |
| **continue** | Skip the current iteration and jump to the next one. |

---

### 📝 Practice Logic Overview
This module covers various practical implementations:
* **Multiplication Tables**: Generating tables for any number `n`.
* **Sum of N Numbers**: Calculating totals using both `for` and `while` loops.
* **Factorial Calculation**: Using iteration to find the product of all positive integers up to `n`.
* **Sequence Traversal**: Printing elements from Lists and Tuples.
