# 📥 Module 05: User Input in Python

### 📌 Definition
The `input()` function in Python allows the program to pause and wait for the user to provide data. By default, **all data collected through `input()` is treated as a String (`str`)**.

---

### 📂 Input Categories & Typecasting

To use the data for calculations, we must convert it using **Explicit Type Conversion**:

1. **Standard Input**: `name = input("Enter Name: ")` → Stores data as a **String**.
2. **Integer Input**: `age = int(input("Enter Age: "))` → Converts input to a **Whole Number**.
3. **Float Input**: `price = float(input("Enter Price: "))` → Converts input to a **Decimal Number**.
