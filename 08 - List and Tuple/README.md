# 📦 Module 08: Lists and Tuples

### 📌 Definition
In Python, **Lists** and **Tuples** are used to store multiple items in a single variable.

---

### 📂 Detailed Categories

#### 1. Lists (Mutable)
* **Definition**: An ordered collection that is **changeable** (mutable). It allows duplicate members.
* **Symbol**: Square brackets `[ ]`.
* **Key Characteristic**: You can modify, add, or remove elements after the list has been created.

#### 2. Tuples (Immutable)
* **Definition**: An ordered collection that is **unchangeable** (immutable).
* **Symbol**: Parentheses `( )`.
* **Key Characteristic**: Once defined, the elements and their order cannot be changed. This makes them faster and safer for data that shouldn't change.

---

### 🛠️ Built-in Methods

| Method | Applicable To | Description |
| :--- | :--- | :--- |
| `.append()` | List | Adds an element at the end of the list. |
| `.sort()` | List | Sorts the list in ascending order. |
| `.reverse()` | List | Reverses the order of the list. |
| `.insert()` | List | Adds an element at a specific index. |
| `.pop()` | List | Removes the element at a specific index (or last item). |
| `.count()` | List & Tuple | Returns the number of times a value appears. |
| `.index()` | List & Tuple | Returns the index of the first occurrence of a value. |

---

### ⚖️ Real-Life Analogy
* **List**: Like a **Shopping List**—you can add items as you remember them or cross them out if you change your mind.
* **Tuple**: Like a **Printed Menu**—the items and prices are fixed and cannot be changed by the customer.
