## 🛠️ Operator Categories

### 1️⃣ Arithmetic Operators
*For mathematical precision.*
| Icon | Operator | Purpose | Syntax |
| :---: | :--- | :--- | :--- |
| ➕ | `+` | Addition | `x + y` |
| ➖ | `-` | Subtraction | `x - y` |
| ✖️ | `*` | Multiplication | `x * y` |
| ➗ | `/` | Division (Float result) | `x / y` |
| 📉 | `//` | Floor Division (Int result) | `x // y` |
| 🔢 | `%` | Modulus (Remainder) | `x % y` |
| ⚡ | `**` | Exponentiation (Power) | `x ** y` |

### 2️⃣ Relational (Comparison) Operators
*For logic and decision making.*
> **Note:** These always return a Boolean value (`True` or `False`).

* ✅ `==` **Equal to**
* ❌ `!=` **Not equal to**
* 📈 `>` **Greater than**
* 📉 `<` **Less than**
* 🔼 `>=` **Greater or equal**
* 🔽 `<=` **Less or equal**

### 3️⃣ Assignment Operators
*Clean and efficient code.*
| Operation | Shortcut | Equivalent To |
| :--- | :--- | :--- |
| **Add & Assign** | `x += 3` | `x = x + 3` |
| **Sub & Assign** | `x -= 3` | `x = x - 3` |
| **Mul & Assign** | `x *= 3` | `x = x * 3` |
| **Exp & Assign** | `x **= 3` | `x = x ** 3` |

### 4️⃣ Logical Operators
*The brains of your conditional statements.*
* `and` : Returns `True` if **both** statements are true.
* `or`  : Returns `True` if **at least one** statement is true.
* `not` : **Reverses** the result (True ↔ False).

## 💎 Pro-Tips & Advanced Concepts (Valuable Additions)

### 🧩 1. Operator Precedence (PEMDAS)
Just like in math, Python follows a specific order. 
1. **Parentheses** `()`
2. **Exponentiation** `**`
3. **Multiplication/Division** `* / // %`
4. **Addition/Subtraction** `+ -`

### 🔍 2. Membership Operators
Great for checking if a value exists in a list or string!
* `in` : Returns True if a sequence contains the value.
* `not in` : Returns True if the value is missing.

### 🆔 3. Identity Operators
Used to compare objects, not just values.
* `is` : True if both variables are the same object.
* `is not` : True if they are different objects.
