# 🚦 Module 07: Conditional Statements

### 📌 Definition
Conditional statements are used to perform different actions based on different conditions. They allow the program to make decisions and execute specific blocks of code.

---

### 📂 Logic Structures

#### 1. The `if` Statement
The most basic form of decision-making. If the condition is **True**, the indented block runs. If **False**, it is skipped.

#### 2. The `elif` (Else If) Statement
Used to check multiple conditions. It only runs if the previous `if` or `elif` conditions were **False**.

#### 3. The `else` Statement
The final fallback. It executes only if **none** of the preceding conditions were met.

#### 4. Nested `if-else`
An `if` statement inside another `if` statement. This is used for multi-layered decision-making.

---

### ⚖️ Key Difference: `if` vs `elif`

* **Multiple `if` blocks**: Python checks **every** `if` statement independently, even if the one before it was True.
* **`if-elif` chain**: Python stops checking as soon as it finds the **first** True condition. This is more efficient.
